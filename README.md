# MC 成就生成器 (MC Advancement Generator)

将 Minecraft 的进阶（Advancement）提示框带入聊天框！这是一款为 AstrBot 打造的图片生成插件，支持自动排版、智能图片提取及画质控制。

## ✨ 核心特性
- **高度还原**：完美呈现 Minecraft 原版的像素字体和九宫格边框。
- **智能提取**：支持自动获取 `@群友` 头像，或者 **回复（引用）** 别人的图片作为成就图标。
- **自定义输出**：通过管理面板自由切换 `PNG`、`JPEG`、`WEBP` 格式，并自由控制画质压缩率！

## 🎮 指令说明
### 1. 普通成就
- **指令**：`/mc成就 [标题] [描述]`
- **示例**：`/mc成就 既然来了 开启了新的一天`

### 2. 挑战模式 (紫色调)
- **指令**：`/mc挑战 [标题] [描述]`
- **示例**：`/mc挑战 屠龙勇士 成功击败了末影龙`

## ⚙️ 后台配置 (WebUI)
在 AstrBot 的 WebUI 插件设置中，你可以调节：
- **输出图片格式**：建议需要透明背景用 `png` 或 `webp`；需要小体积用 `jpeg`。
- **输出图片质量**：1-100，默认 90。压低此项可有效防止部分平台图片发送缓慢。

> **💡 注意**：保存 JPEG 时透明背景会变为深灰色填充，这是正常现象。
